# MultiFreak releases

Downloads for **MultiFreak**, a multi-track real-time spectrum analyzer (AU + VST3) by Obscura Lux.

Go to **[Releases](../../releases/latest)** and download `MultiFreak-<version>-macOS.dmg`
(macOS 12 or later, Apple Silicon and Intel).

MultiFreak checks this page for new versions and can install them by itself (Options ▸ Updates).
Each release includes `multifreak-update.json`, which lists the update package with its size and
SHA-256 hash, and `multifreak-update.json.sig`, an RSA signature of that file. MultiFreak installs an
update only if the signature, the hash and the Apple Developer ID code signature all check out.
